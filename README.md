# Stock-Sim

This is a prediction simulator I used to help expand my knowledge in HTML,  CSS, and JavaScript, trade real time stocks and watch live canvas charts and play high stakes prediction games.

How to use:
-Open the live demo link or open index.html in any web browser.
-Select different assets from the left market sidebar to view their live updating price charts
-Use the trade panel at the bottom of the chart to buy or sell shares using your starting $10,000 cash balance.
-Use the right sidebar tabs to switch between the 30 second price direction predict game, your active portfolio positions, and the breaking news feed.
-Watch how procedural news alerts dynamically shift asset prices in real time!

Features:
Realtime HTML Canvas charting engine with auto scaling price grids and live historical rendering
-30 second binary options prediction mini game complete with countdown timers with multiplied payout mechanics
-Procedural news generator that pushes breaking market headlines which directly impact individual stock prices
-Portfolio tracker monitoring live shares, average cost basis, etc
-Web audio API that requires no external audio files

How to run it locally:
-Clone or download this repo
-Open the project folder
-Double click index.html to open it directly on your web browser

This was created as a coding project to practice advanced web development concepts like the canvas API, web audio API, and real time state management, huge thanks to the online developer community and tutorials as well as W3SCHOOLS for helping m understand core concepts required to complete this project!
